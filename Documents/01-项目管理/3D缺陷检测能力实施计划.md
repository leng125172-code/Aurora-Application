# 3D 缺陷检测能力实施计划

## 目标

建立“扫描点云与 CAD 工艺模型比较”的可靠检测链路，输出可解释的
`OK / NG / UNKNOWN` 结果。在基础链路稳定后，再逐步补充全局姿态搜索、
多实例搜索、GPU 加速和完整 GD&T 检测体系。

## 优先级

| 优先级 | 能力 | 实施原因 |
|---|---|---|
| P0 | CAD 三角面均匀采样 | OBJ 原始顶点密度不均，直接比较会造成参考模型采样失真 |
| P0 | 模型法向量与有符号点到面距离 | 判断凸起、凹陷和超差方向的基础 |
| P0 | 局部区域公差配置 | 工业工件不同部位通常不能共用一个阈值 |
| P0 | 不可见面、扫描盲区过滤 | 避免把未扫描区域误判为缺料 |
| P1 | 配准置信度与不确定度评估 | 配准不可信时必须阻止错误的 OK/NG 判定 |
| P1 | 基于法向量的公差带检测 | 支持正负公差、单边公差及沿曲面法向检测 |
| P1 | 全局姿态搜索 | 支持工件初始姿态未知的场景 |
| P1 | 对称工件姿态歧义处理 | 避免规则工件出现错误或不稳定姿态 |
| P2 | 超大点云分块与并行加速 | 在算法正确后改善生产节拍 |
| P2 | 多实例三维模型搜索 | 支持同一场景存在多个相同工件 |
| P2 | GPU 加速 | 加速最近邻、距离计算、法向量和配准 |
| P3 | 完整 GD&T 检测体系 | 依赖基准、特征、尺寸和公差语义体系 |

## 第一阶段：缺陷比较 MVP

### CAD 三角面均匀采样

新增“CAD 网格采样”算子，按三角形面积分配采样数量，并使用重心坐标在
三角形内部均匀采样。

建议配置：

- 采样间距
- 最大采样点数
- 是否保留原始顶点
- 是否在尖锐边缘加密
- 随机种子
- 法向量方向修复

每个采样点至少关联：

- Position
- Normal
- TriangleId
- SurfaceRegionId
- Material/Group
- ToleranceProfileId

### 有符号点到面距离

计算扫描点到 CAD 三角面的最近点，并沿模型法向量计算有符号距离：

```text
signedDistance = dot(scanPoint - modelPoint, modelNormal)
```

输出内容：

- 有符号距离和绝对距离
- 最近模型点和最近三角面
- 模型法向量
- 扫描法向量与模型法向量夹角
- 匹配是否有效
- 正向、负向超差分类

应使用三角形最近点，而不是只使用最近顶点。

### 局部公差区域

每个模型区域支持独立的正负公差、预警阈值、最小缺陷面积和最小缺陷点数。

区域来源支持：

- OBJ Group 或 Material
- 三角面编号集合
- 用户在三维模型上选择的区域
- 平面、圆柱、球等几何特征
- 相对基准或特征的空间范围

判定指标包括：

- 连续缺陷面积
- 缺陷点数量
- 最大偏差和平均偏差
- 连续缺陷长度
- 缺陷簇数量

### 可见面与扫描盲区过滤

- 根据相机位置和模型法向量过滤背面
- 根据相机视锥过滤视野外区域
- 使用深度缓冲或射线检测判断遮挡
- 对扫描边界设置无效缓冲区
- 将孔洞、反光区和低置信度区域标记为 UNKNOWN

没有被有效扫描的区域不能直接判定为缺料或 NG。

## 第二阶段：检测可靠性

### 配准置信度与不确定度

配准结果增加：

- 内点比例
- 重叠率
- RMSE 和最大残差
- 法向一致率
- 变换迭代稳定性
- 平移和旋转不确定度
- 是否达到可信阈值

配准置信度不足时，不执行缺陷 OK/NG，返回
`ALIGNMENT_FAILED` 或 `UNKNOWN`。

### 基于法向量的公差带

支持：

- 对称公差
- 非对称公差
- 仅允许凸起或仅允许凹陷
- 按模型区域分别配置
- 忽略切向滑动
- 法向夹角过大时拒绝匹配

### 缺陷聚类与结果输出

将离散超差点聚类为实际缺陷，输出：

- 缺陷面积、长度和最大深度/高度
- 缺陷中心、包围盒和关联模型区域
- 凸起、凹陷、缺料、未知等缺陷类型
- 缺陷着色点云和模型叠加结果

工作流最终输出建议包括：

```text
inspection_status
alignment_status
coverage_ratio
defect_count
max_positive_deviation
max_negative_deviation
defect_ratio
unknown_ratio
defect_list_json
colored_comparison_cloud
model_overlay_mesh
```

## 第三阶段：全局搜索与复杂姿态

### 全局姿态搜索

1. 模型与场景体素化
2. 计算法向量和局部特征
3. 特征匹配
4. RANSAC 生成候选姿态
5. 点到面 ICP 精配准
6. 候选姿态评分
7. 遮挡和可见面重新验证
8. 输出 Top-K 姿态及置信度

先实现单实例、有限姿态范围，再扩展到任意姿态。

### 对称工件姿态处理

模型配置旋转对称轴、旋转周期、镜像对称、等价姿态集合及消歧关键特征。
对于检测结果不受姿态影响的完全对称工件，将等价姿态视为同一结果。

### 多实例模型搜索

重复执行“搜索最佳实例、抑制已匹配区域、搜索下一实例”，直到匹配分数不足
或达到实例数量上限。每个实例独立输出姿态、置信度、覆盖率和缺陷结果。

## 第四阶段：性能

### 超大点云分块

- 使用八叉树或体素索引
- 根据 CAD 包围盒裁剪
- 基于 ROI 按需加载
- 分块执行最近邻和距离计算
- 合并跨分块缺陷簇
- 低分辨率搜索和配准，高分辨率最终检测

### GPU 加速

优先加速：

1. 最近邻查询
2. 点到三角面距离
3. 法向量计算
4. ICP 对应点建立
5. 可见性深度缓冲
6. 特征描述子计算

保留 CPU 实现作为结果基准和回退路径。

## 第五阶段：GD&T

推荐顺序：

1. 表面轮廓度
2. 平面度
3. 圆度
4. 圆柱度
5. 平行度、垂直度和倾斜度
6. 位置度
7. 同轴度或同心度
8. 跳动和全跳动

完整 GD&T 还需要基准 A/B/C、基准体系、几何特征、实际配合包络、
材料条件、测量不确定度及标准版本等基础能力。

## 推荐实施顺序

```text
CAD 面内采样
  → 模型法向量
  → 点到三角面有符号距离
  → 局部公差
  → 可见性与盲区过滤
  → 缺陷聚类
  → OK / NG / UNKNOWN
  → 配准置信度
  → 全局姿态搜索
  → 对称姿态与多实例
  → 分块与 GPU
  → 完整 GD&T
```

首批优先实现 CAD 面内采样、有符号点到三角面距离、局部公差区域和不可见
区域过滤。这四项对缺陷检测误报率和漏报率的改善最直接。
