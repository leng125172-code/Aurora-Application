# 3D 检测补充交互设计

## 1. 设计目标

本设计补充以下四类交互：

1. 以标准 OK 图的标注特征为基准，在实际产品中定位对应特征并计算安装角度。
2. 最终结果按 ROI 的实际语义叠加，不再对所有 ROI 使用同一种显示方式。
3. 增加可配置 X、Y、Z 旋转角的斜视图输出算子。
4. 将工作流输出统一改为在结束节点配置，废弃独立编辑输出配置的旧交互。

## 2. 安装角度检测

### 2.1 核心原则

标准 OK 图用于定义“测哪里”和“标准角度是多少”，实际产品图用于计算本次
测量结果。不能直接在标准图上得到实际产品角度，也不能要求实际产品与标准图
中的线段位置完全重合。

完整链路：

```text
标准 OK 图标注两条特征线
        ↓ 保存特征模板、匹配区域、标称角度
实际产品图进入
        ↓ 在匹配区域内查找两条对应特征
得到实际线段/拟合直线
        ↓ 必要时延长直线求交
计算夹角、偏差和 OK/NG/UNKNOWN
```

### 2.2 标准图标注模式

进入角度检测节点的“编辑特征”后，右侧属性面板显示：

- 标准图：选择或刷新当前标准 OK 图。
- 特征 1、特征 2：分别绘制两个端点，形成两条有方向的标注线。
- 匹配区域：每条特征线可配置独立的矩形或多边形搜索区。
- 角度类型：锐角、钝角、有向角；默认使用两条无向直线的最小夹角。
- 标称角度：默认由标准图两条标注线自动计算，允许人工修正。
- 允许偏差：下偏差、上偏差。
- 最小线段长度、最大拟合残差、最低匹配置信度。

绘制规则：

- 首次点击确定起点，第二次点击确定终点。
- 线段端点支持拖动；按 `Esc` 取消本次绘制，`Delete` 删除选中特征。
- 两条线使用不同颜色，并显示“特征 1 / 特征 2”。
- 标准图上实时显示两条直线延长后的交点、角弧和标称角度。
- 两条线接近平行时不绘制远距离交点，显示“近似平行”，角度仍按方向向量计算。

保存的是标准图坐标下的端点、搜索区、角度选择规则和公差，不保存仅用于显示的
延长线。

### 2.3 实际产品匹配与计算

运行时先使用产品定位/配准结果，将标准标注和搜索区映射到实际产品图；再在各自
搜索区内提取边缘或线特征，并拟合无限直线。

两条检测线段不相交时：

- 使用拟合后的无限直线求交点。
- 交点在图像合理显示范围内时，结果图用虚线延长两条线至交点。
- 交点过远或数值不稳定时，不强制画到交点，只显示方向平行的辅助虚线。
- 角度计算始终基于拟合直线方向，不以可见线段是否相交为前提。

推荐计算约定：

```text
方向夹角 θ = acos(clamp(|d1 · d2|, 0, 1))，范围 0°～90°
若选择钝角：结果 = 180° - θ
若选择有向角：按特征起终点方向计算，范围 -180°～180°
偏差 = 实测角度 - 标称角度
```

若任一特征未找到、有效点不足、拟合残差超限或置信度不足，状态为 `UNKNOWN`，
不得按普通 `NG` 展示。

### 2.4 调试与结果交互

调试区提供“标准标注 / 映射位置 / 实际拟合”三层开关。选中某条特征时，同时
高亮它的标准标注、实际搜索区和实际拟合线。

结果图显示：

- 实际有效线段：实线。
- 延长部分：虚线。
- 交点：圆点。
- 角弧、实测角度、标称角度和偏差。
- `OK` 为绿色，`NG` 为红色，`UNKNOWN` 为黄色或灰色。

悬停结果卡片时高亮对应图形；点击“重新标注”返回标准图编辑模式，并保留原配置，
只有点击保存后才覆盖。

## 3. ROI 结果叠加

### 3.1 按 ROI 语义选择叠加方式

| ROI 实际功能 | 最终结果叠加 |
|---|---|
| 选择平面 | 高亮完整选中平面，建议使用半透明面片并显示轮廓 |
| 选择平面内区域 | 只高亮区域本身，显示半透明填充、边界和 ROI 名称 |
| 提取/选择 ROI 区域点云 | 不叠加 ROI；点云本身是否输出由工作流输出配置决定 |

前端不能仅根据数据类型推断叠加方式。节点元数据或运行结果应提供稳定的
`overlayMode`：

```ts
type RoiOverlayMode = 'plane' | 'region' | 'none'
```

建议映射：

- 选择拟合平面：`plane`
- 定义平面区域：`region`
- 提取平面区域点云：`none`

### 3.2 图层管理

结果预览右上角增加“叠加层”入口，按工作流执行顺序列出可显示项。每项支持：

- 显示/隐藏。
- 颜色和透明度。
- 单项定位。
- 恢复默认样式。

默认只展示被配置为最终结果的图像/点云及其可视化 ROI，避免把所有中间节点
叠加到最终结果。多个平面或区域重叠时，当前选中项提升亮度，其他项降低透明度。

当 ROI 点云节点为 `none` 时，图层列表不生成占位项，也不显示空图层提示。

## 4. 斜视图算子

现有“彩色点云转倾斜视图”作为最终结果生成算子，属性面板包含：

| 配置项 | 控件 | 建议范围/默认值 |
|---|---|---|
| X 轴旋转角 | 数字框 + 滑杆 | `-180°～180°`，默认 `30°` |
| Y 轴旋转角 | 数字框 + 滑杆 | `-180°～180°`，默认 `0°` |
| Z 轴旋转角 | 数字框 + 滑杆 | `-180°～180°`，默认 `30°` |
| 输出宽度/高度 | 数字框 | 使用系统默认分辨率 |
| 背景颜色 | 颜色选择 | 深色 |
| 自动适配画布 | 开关 | 开 |

旋转顺序必须固定并在属性面板提示，例如“按 Y → X → Z 顺序旋转”。前端预览和
后端算子必须使用相同顺序、角度正方向和度数单位。

交互规则：

- 修改角度后使用防抖预览，不立即保存工作流。
- 提供正视图、俯视图、左视图、等轴测四个预设。
- 点击“设为结果视图”后，将该算子的图像输出绑定到结束节点。
- 运行完成后，斜视图与其他结果图一起出现在最终结果图列表中。

## 5. 工作流输出配置

### 5.1 唯一配置入口

输出变量的唯一编辑入口是画布中的结束节点。旧的独立“输出变量配置”多选框和
`PUT /api/app/workflow/{id}/output-config` 编辑交互不再使用。

用户点击结束节点后，右侧面板显示“输出绑定”列表：

| 字段 | 说明 |
|---|---|
| 变量名称 | 从当前图中已产生的运行时变量中选择，工作流输出内唯一 |
| Display 名称 | 面向用户/调用方的显示文字，可为空；为空时使用变量名称 |
| 类型 | 根据来源变量只读回显 |
| 操作 | 上移、下移、删除 |

支持“添加输出”。变量选择器按节点分组，并只列出结束节点之前可用的变量。图片、
点云、标量均可绑定。结束节点至少配置一个输出。

保存到图数据的示例：

```json
{
  "id": "end",
  "type": "end-node",
  "properties": {
    "inputBindings": {
      "output1": "tilted_result_blob_key",
      "output2": "install_angle_status"
    },
    "inputBindingSources": {
      "output1": "variable",
      "output2": "variable"
    },
    "inputBindingDisplayNames": {
      "output1": "结果视图",
      "output2": "安装角度状态"
    }
  }
}
```

后端目前从结束节点 `inputBindings` 的“值”自动推导工作流输出，因此来源变量名
必须唯一、有效，并且 `inputBindingSources` 必须为 `variable`。

### 5.2 接口与保存时序

打开已有工作流：

1. `GET /api/app/workflow/{id}`。
2. 从 `graphData` 中找到唯一的 `type === "end-node"` 节点。
3. 使用其 `properties.inputBindings` 和 `inputBindingDisplayNames` 回显输出列表；
   Display 名称缺失时使用变量名称。
4. 响应中的 `outputVariables` 仅用于兼容或一致性检查，不作为可编辑数据源。

更新工作流：

1. 前端在内存中更新结束节点绑定。
2. 执行本地校验。
3. `PUT /api/app/workflow/{id}` 一次性保存完整 `graphData`。
4. 后端校验图，并从结束节点自动更新实体的 `OutputVariables`。

新建工作流：

1. 创建编辑器草稿时自动放置开始节点和结束节点，不立即请求后端。
2. 用户完成节点、连线和结束节点输出配置。
3. 执行本地校验。
4. `POST /api/app/workflow` 一次性提交完整 `graphData`。
5. 创建成功后以后端返回的工作流 ID 和图数据替换本地草稿。

因此，新建时不存在“必须先取得工作流 ID 才能配置输出”的问题。输出配置是
`graphData` 的组成部分，应与工作流一起原子创建。不要采用“先创建空工作流，再调
旧输出接口”的两阶段保存，否则会产生暂时不可运行的工作流，并可能出现第二步
失败后的不一致状态。

### 5.3 对旧接口报错的解释

报错：

```text
输出变量由结束节点自动生成，请在工作流结束节点中调整输出绑定后保存。
```

表示前端仍在调用旧的 `PUT /api/app/workflow/{id}/output-config`，且提交列表与
结束节点推导结果不同。正确处理是停止调用该接口，修改结束节点后调用工作流
创建或更新接口。

`GET /api/app/workflow/{id}/output-config` 可暂时用于只读兼容；`PUT` 只接受与
结束节点完全一致的列表，已不具备独立配置能力。建议后续在接口文档和 OpenAPI
中标记为 deprecated，待所有前端迁移后删除。

## 6. 保存校验与异常提示

保存前按顺序校验：

1. 开始节点和结束节点各一个。
2. 结束节点至少绑定一个输出，输出键和来源变量不重复。
3. 来源变量存在，且类型与结果用途兼容。
4. 安装角度已完成两条标准特征及搜索区标注。
5. 标称角度、公差和拟合质量参数合法。
6. 斜视图旋转角和输出尺寸在允许范围。

错误应定位到具体节点和字段。点击错误项自动选中节点并滚动到对应控件。网络保存
失败时保留本地草稿和未保存标记，不清空结束节点输出配置。

## 7. 验收要点

- 标准图两条线段不相交时，实际结果仍能通过延长线正确计算并展示角度。
- 实际产品位置变化后，检测使用匹配到的实际特征，而非标准图原坐标直接测量。
- 平面、面内区域、ROI 点云三种功能分别呈现完整面、局部区域、不叠加。
- X/Y/Z 任一旋转配置变化后，斜视图方向与后端输出一致。
- 新建工作流只需一次创建请求即可保存结束节点输出。
- 编辑输出后只调用工作流更新接口，不再出现旧输出配置接口报错。
- `UNKNOWN` 与 `NG` 在状态、颜色和原因提示上明确区分。
