# 工作流运行时新增接口列表

> 更新时间：2026-07-07
> 模块：Workflow Runtime
> 路由前缀：`/api/app/workflow`

## 0. 术语约定

- `WorkflowDefinition`：单个工作流，等价项目内可编排单元。
- `Binding`：项目内工作流启用与顺序配置。
- `Deployment`：根据当前绑定发布出的部署快照，等价“写入 PLC”的版本。
- `Task`：按某个激活部署或 legacy 回退规则创建出来的后台执行任务。
- `Execution`：单个工作流运行/调试会话。

## 1. 项目绑定接口

### 1.1 查询项目绑定

- Method: `GET`
- Path: `/api/app/workflow/projects/{projectId}/bindings`
- 对应方法：`GetProjectBindingsAsync`
- 说明：返回项目下全部工作流及其当前绑定状态；未绑定工作流也会返回，默认 `isEnabled=false`。

响应体：`List<WorkflowProjectBindingDto>`

关键字段：

- `id`
- `projectId`
- `workflowId`
- `workflowName`
- `isEnabled`
- `orderNo`

### 1.2 批量更新项目绑定

- Method: `PUT`
- Path: `/api/app/workflow/projects/bindings`
- 对应方法：`UpdateProjectBindingsAsync`
- 说明：按工作流粒度更新启用状态与执行顺序。

请求体（`WorkflowProjectBindingBatchUpdateInput`）:

```json
{
  "projectId": "guid",
  "items": [
    {
      "workflowId": "guid",
      "isEnabled": true,
      "orderNo": 10
    }
  ]
}
```

## 2. 项目部署接口

### 2.1 查询项目部署历史

- Method: `GET`
- Path: `/api/app/workflow/projects/{projectId}/deployments`
- 对应方法：`GetProjectDeploymentsAsync`

响应体：`List<WorkflowProjectDeploymentDto>`

关键字段：

- `id`, `projectId`, `revision`, `status`
- `isCurrentActive`
- `snapshotHash`, `itemCount`
- `activatedAt`, `activatedBy`, `creationTime`
- `canActivate`, `canReactivate`, `canRollback`

响应示例：

```json
[
  {
    "id": "8f5f6a61-9f02-44a4-9b58-bfe4f7b2ab31",
    "projectId": "b30f3c9d-c7c1-4a5f-aefb-8f8ab58d4f0d",
    "revision": 7,
    "status": 1,
    "isCurrentActive": true,
    "canActivate": false,
    "canReactivate": true,
    "canRollback": false,
    "snapshotHash": "c6de3f0e3f5d5e7ad6676bbf0b9f95df",

    "creationTime": "2026-07-07T09:20:00.000Z"
  }

```

### 2.2 发布项目部署快照

- Method: `POST`
- Path: `/api/app/workflow/projects/{projectId}/deployments`
- 对应方法：`PublishProjectDeploymentAsync`
- 说明：根据当前已启用绑定发布新的部署版本；快照会记录工作流名称、顺序与 `GraphData` 指纹。

### 2.3 激活部署

- Method: `POST`
- Path: `/api/app/workflow/deployments/{deploymentId}/activate`
- 对应方法：`ActivateProjectDeploymentAsync`
- 说明：将指定部署切换为当前激活版本，并归档同项目其他已激活部署。

### 2.4 重新激活部署

- Method: `POST`
- Path: `/api/app/workflow/deployments/{deploymentId}/reactivate`
- 对应方法：`ReactivateProjectDeploymentAsync`
- 说明：对历史已发布或已归档版本重新激活；若目标已处于激活状态，直接返回当前版本信息。

### 2.5 回滚到历史部署

- Method: `POST`
- Path: `/api/app/workflow/deployments/{deploymentId}/rollback`
- 对应方法：`RollbackProjectDeploymentAsync`
- 说明：回滚到指定历史部署，本质上是激活旧 revision；若目标已是当前激活版本，则返回业务错误。

## 3. 项目任务接口（Hangfire）

### 3.1 创建并入队项目任务

- Method: `POST`
- Path: `/api/app/workflow/tasks`
- 对应方法：`EnqueueProjectTaskAsync`
- 说明：优先按当前激活部署解析执行工作流列表；若无激活部署，则回退到 legacy 模式，执行项目下全部工作流。

请求体（`WorkflowProjectTaskEnqueueInput`）:

```json
{
  "name": "任务名称",
  "projectId": "guid",
  "startType": 0,
  "onErrorAction": 0
}
```

响应体（`WorkflowProjectTaskEnqueueResultDto`）关键字段：

- `taskId`, `projectId`, `workflowCount`, `hangfireJobId`
- `deploymentId`, `deploymentRevision`

响应示例（激活 deployment 模式）：

```json
{
  "taskId": "a3d43b13-8b1b-4f6f-84fe-c525f0bcf5ab",
  "projectId": "b30f3c9d-c7c1-4a5f-aefb-8f8ab58d4f0d",
  "workflowCount": 3,
  "hangfireJobId": "21873",
  "deploymentId": "8f5f6a61-9f02-44a4-9b58-bfe4f7b2ab31",
  "deploymentRevision": 7
}
```

响应示例（legacy 回退模式）：

```json
{
  "taskId": "251db42c-cf15-4524-a7e3-bddf5f8b4e08",
  "projectId": "b30f3c9d-c7c1-4a5f-aefb-8f8ab58d4f0d",
  "workflowCount": 2,
  "hangfireJobId": "21874",
  "deploymentId": null,
  "deploymentRevision": null
}
```

### 3.2 查询项目任务列表

- Method: `GET`
- Path: `/api/app/workflow/tasks`
- 对应方法：`GetProjectTasksAsync`
- Query：`projectId`, `skipCount`, `maxResultCount`

### 3.4 请求取消项目任务

- Method: `POST`
- Path: `/api/app/workflow/tasks/{taskId}/cancel`

### 3.5 修改项目任务

- Method: `PUT`
- Path: `/api/app/workflow/tasks/{taskId}`
- 说明：仅允许修改任务名称和任务级错误策略；执行中的任务不允许修改。

### 3.6 删除项目任务

- Method: `DELETE`
- Path: `/api/app/workflow/tasks/{taskId}`

## 4. 执行会话接口

### 4.1 触发执行

- Method: `POST`
- Path: `/api/app/workflow/executions`

### 4.2 调试单步执行

- Method: `POST`
- Path: `/api/app/workflow/executions/{executionId}/steps`

### 4.3 查询执行会话状态

- Method: `GET`
- Path: `/api/app/workflow/executions/{executionId}`

### 4.4 停止调试会话

- Method: `DELETE`
- Path: `/api/app/workflow/executions/{executionId}`

## 5. 联调建议

1. 先配置项目绑定，再发布 deployment，并显式激活目标 revision。
2. 创建任务后，优先检查返回中的 `deploymentId` / `deploymentRevision`，确认本次任务绑定的是哪个部署版本。
3. 若创建任务时报“发布后发生变化”，说明部署快照中的工作流 `GraphData` 指纹与当前库中版本不一致，需要重新发布部署。
4. 前端可直接使用 `canActivate`、`canReactivate`、`canRollback` 决定部署列表上的操作按钮是否可点击。
