# 安装角度检测设计记录

## 使用场景

安装角度主要用于检测产品、支架、盖板、PCB、连接器等部件相对产品基准
是否装歪。第一版采用“基准平面 ROI + 安装平面 ROI”的双特征测量方式。

普通单 ROI 不能完整定义角度。一个安装角度至少需要：

- 基准特征 ROI：建立产品基准方向
- 被测特征 ROI：建立安装部件方向
- 标称角度和分方向公差

## 第一版工作流

```text
原始点云
 ├→ 选择基准平面 → 定义 ROI-A → 提取区域点 → 局部平面拟合
 └→ 选择安装平面 → 定义 ROI-B → 提取区域点 → 局部平面拟合
                                                ↓
                                      安装平面角度检测
                                                ↓
                              tiltX / tiltY / totalTilt
                              OK / NG / UNKNOWN
```

ROI 提取后必须重新拟合局部平面。否则修改 ROI 时，测量结果可能仍然来自整个
平面的旧拟合结果。

## 坐标和角度定义

以基准平面法向量作为局部 Z 轴。

- 将全局 X 轴投影到基准平面，作为局部 X 轴
- 全局 X 轴接近基准法向时，自动改用全局 Y 轴
- 局部 Y 轴由右手坐标系计算
- 安装面法向自动翻转到与基准法向同一半球

输出：

- `tilt_x`：安装面绕基准局部 X 轴的有符号倾角
- `tilt_y`：安装面绕基准局部 Y 轴的有符号倾角
- `total_tilt`：两个平面法向量之间的最小夹角
- `deviation_x`、`deviation_y`：相对标称角度的偏差
- `total_deviation`：分方向偏差合成值

第一版不检测绕基准法向的平面内旋转 `twistZ`。仅靠两个平面法向量无法确定
该角度，后续需要增加边线、槽方向、孔中心连线或 CAD 坐标轴作为方向特征。

## 判定规则

配置：

- X、Y 标称角度
- X、Y 最小和最大允许偏差
- 最大合成倾角偏差
- 每个 ROI 最小有效点数
- 最大平面拟合 RMSE

结果状态：

- `OK`：拟合质量有效，所有角度偏差均在公差内
- `NG`：拟合质量有效，但至少一个角度指标超差
- `UNKNOWN`：点数不足、平面参数无效或拟合残差过大

`UNKNOWN` 不应当作为普通 NG 使用。它表示当前数据不足以形成可信的安装判定。

## 第二版

第二版增加以下算子：

### 轴线与平面安装角度

用于销轴、螺柱、连接器、镜头和管件相对底座平面的安装检测。

```text
基准面 ROI → SVD 平面拟合 ─────┐
轴或圆柱 ROI → 直线/圆柱拟合 ──┴→ 安装轴线与平面检测
```

输出 X/Y 分方向倾角、轴线与平面法向夹角、轴线与平面夹角以及三态结果。
轴线参数同时兼容 3D 直线拟合的 6 参数格式和圆柱拟合的 7 参数格式；质量
评估分别使用点到轴线残差和点到圆柱面径向残差。

### 轴线与轴线安装角度

用于两根轴、管件、孔轴或连接器的平行度和指定夹角检测。轴线按无向几何
特征处理，输出 `0°～90°` 的最小夹角，避免拟合方向正负翻转造成结果跳变。

### 平面内旋转 twistZ

需要在基准面内分别提供基准方向和安装方向，例如边线、槽方向、孔中心连线。
两个方向投影到基准平面后，绕基准面法向计算 `-180°～180°` 有符号旋转角。

三个算子都使用 `OK / NG / UNKNOWN`：

- ROI 点数不足或拟合残差过大时返回 UNKNOWN
- 数据可信但角度超差时返回 NG
- 数据可信且角度合格时返回 OK
