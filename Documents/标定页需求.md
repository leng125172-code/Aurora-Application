# 标定功能 AI提示词

用于多目相机或多目结构光相机标定。

## 标定步骤 Step 1

### 设备类型(选择)

1. 无光系列

    | 设备类型  | 相机数量 | 相机构成                          | 相机位置                         | 结构光数量 | 结构光构成 | 结构光位置 |
    | --------- | -------- | --------------------------------- | -------------------------------- | ---------- | ---------- | ---------- |
    | 2 目 0 光 | 2        | 主相机 (左)、从相机 (右)          | 左右水平对称排布，同平面         | 0          | —          | —          |
    | 3 目 0 光 | 3        | 主相机 (中上)、左下相机、右下相机 | 左下 / 中上 / 右下等腰三角形排布 | 0          | —          | —          |

2. 单光系列

    | 设备类型  | 相机数量 | 相机构成                              | 相机位置                         | 结构光数量 | 结构光构成 | 结构光位置 |

    | 1 目 1 光 | 1        | 主相机                                | 结构光旁侧 / 同轴前置            | 1          | 主结构光   | 整机中心位 |
    | 2 目 1 光 | 2        | 主相机 (左)、从相机 (右)              | 左右水平对称排布，同平面         | 1          | 主结构光   | 整机中心位 |
    | 3 目 1 光 | 3        | 主相机 (中上)、左下从相机、右下从相机 | 左下 / 中上 / 右下等腰三角形排布 | 1          | 主结构光   | 整机中心位 |
    |           |          |                                       |                                  |            |            |            |

> 无光系列位置调节：
> 2 目 必须需要三个电机:每个相机配置一个旋转电机，相机之间距离通过一个电机控制。
> 3 目 必须需要三组多轴云台:每个相机配置一组多轴云台，相机之间距离通过一个电机控制。
> 结构光位置固定不可调节
>
> 单光系列位置调节：
> 1 目 必须需要两个电机:相机配置一个旋转电机，相机与结构光之间距离通过一个电机控制。
> 2 目 必须需要三个电机:每个相机连接配置一个旋转电机，相机之间距离通过一个电机控制。
> 3 目 必须需要三组多轴云台:每个相机连接配置一组多轴云台，三个云台之间距离通过一个电机控制。
> 结构光位置固定不可调节

## 标定步骤 Step 2

### 配置电机参数

旋转电机，设置原点。编码器位置软限位。执行回原(并没有直接能用的回原，需要先判断当前位置，>远点)。
距离电机，设置回原方式。编码器位置软限位。执行回原。
联动软限位，当旋转/距离电机处于什么位置是，禁止执行什么操作。多组限制。

### 配置云台组(仅三目支持，选择非三目相机，不显示这个参数配置)

创建云台组。
将多个电机绑定到同一云台组（如 X 轴旋转（必须）、Y 轴旋转（必须）、Z 轴旋转（非必须）、Z 轴平移（非必须））
支持云台组整体控制，可一键控制云台回原或移动到指定位置

### 绑定设备

相机绑定，把已连接的相机，按选择进行位置绑定，如相机1绑定主相机位置，相机2绑定从相机位置，相机3绑定从相机位置。

再把电机位置进行关联。

3 目 相机是绑定的配置好的绑定云台
