
# 表结构

## AbpProCalibProjects 设备标定项目（聚合根）

| 字段名 | 类型 | 长度 | 允许空 | 说明 |
| ------ | ---- | ---- | ------ | ---- |
| Id | Guid | - | N | 主键 |
| Name | nvarchar | 256 | N | 项目名称 |
| Description | nvarchar | 1024 | Y | 项目描述 |
| DeviceSeries | int | - | N | 设备系列（0=无光系列，1=单光系列） |
| DeviceType | int | - | N | 设备类型（0=2目0光，1=3目0光，2=1目1光，3=2目1光，4=3目1光） |
| CameraCount | int | - | N | 相机数量 |
| ProjectorCount | int | - | N | 结构光数量 |
| CalibStatus | int | - | N | 标定状态（0=初始化中，1=电机配置中，2=电机限制配置中，3=云台配置中，4=相机配置中，5=结构光配置中，6=设备绑定中，7=已完成） |
| CreationTime | datetime2 | - | N | 创建时间 |
| CreatorId | Guid | - | Y | 创建人ID |
| LastModificationTime | datetime2 | - | Y | 最后修改时间 |
| LastModifierId | Guid | - | Y | 最后修改人ID |
| IsDeleted | bit | - | N | 逻辑删除标记 |
| DeletionTime | datetime2 | - | Y | 删除时间 |
| DeleterId | Guid | - | Y | 删除人ID |

---

## AbpProCalibMotorParams 电机参数表

| 字段名 | 类型 | 长度 | 允许空 | 说明 |
| ------ | ---- | ---- | ------ | ---- |
| Id | Guid | - | N | 主键 |
| CalibProjectId | Guid | - | N | 所属标定项目ID（关联AbpProCalibProjects） |
| MotorAxisId | Guid | - | N | 电机轴ID（关联AbpProMotorAxes） |
| MotorType | int | - | N | 电机类型（0=旋转电机，1=距离电机） |
| EncoderResolution | int | - | N | 编码器分辨率（脉冲/圈） |
| GearRatio | decimal | - | N | 减速比 |
| MechanicalOriginPosition | decimal | - | N | 机械原点位置 |
| OriginDirection | int | - | N | 回原方向（0=正向，1=反向） |
| PositiveSoftLimit | decimal | - | N | 正方向软限位（旋转时单位：度°，距离时单位：mm） |
| NegativeSoftLimit | decimal | - | N | 负方向软限位（旋转时单位：度°，距离时单位：mm） |
| HomeSpeed | decimal | - | N | 回原速度 |
| HomeAcceleration | decimal | - | N | 回原加速度 |
| CurrentPosition | decimal | - | Y | 当前位置（实时更新） |
| IsOriginLocked | bit | - | N | 原点是否已锁定 |
| CreationTime | datetime2 | - | N | 创建时间 |
| CreatorId | Guid | - | Y | 创建人ID |
| LastModificationTime | datetime2 | - | Y | 最后修改时间 |
| LastModifierId | Guid | - | Y | 最后修改人ID |

## AbpProCalibGimbalGroups 云台组表

> 云台组是由多个电机轴组合而成的独立逻辑设备，不绑定具体标定项目。
> 在 Step 7 设备绑定时，通过 `AbpProCalibDeviceBindings.BoundGimbalGroupId` 引用。

| 字段名 | 类型 | 长度 | 允许空 | 说明 |
| ------ | ---- | ---- | ------ | ---- |
| Id | Guid | - | N | 主键 |
| Name | nvarchar | 256 | N | 云台组名称 |
| Description | nvarchar | 1024 | Y | 云台组描述 |
| MaxSpeed | decimal | - | N | 最大速度 |
| Acceleration | decimal | - | N | 加速度 |
| AccelerationTime | decimal | - | N | 加速时间（ms） |
| DecelerationTime | decimal | - | N | 减速时间（ms） |
| IsEnabled | bit | - | N | 是否启用 |
| CreationTime | datetime2 | - | N | 创建时间 |
| CreatorId | Guid | - | Y | 创建人ID |
| LastModificationTime | datetime2 | - | Y | 最后修改时间 |
| LastModifierId | Guid | - | Y | 最后修改人ID |

---

## AbpProCalibDeviceBindings 设备绑定表

| 字段名 | 类型 | 长度 | 允许空 | 说明 |
| ------ | ---- | ---- | ------ | ---- |
| Id | Guid | - | N | 主键 |
| CalibProjectId | Guid | - | N | 所属标定项目ID（关联AbpProCalibProjects） |
| BindingType | int | - | N | 绑定类型（0=相机绑定，1=电机绑定，2=投射器绑定） |
| SourceDeviceId | Guid | - | N | 源设备ID（可能是相机、电机或投射器） |
| TargetRole | nvarchar | 128 | N | 目标角色（如"主相机"、"左相机"、"右相机"、"X轴旋转电机"等） |
| BoundCameraParamId | Guid | - | Y | 绑定的相机参数ID（仅当BindingType=0时） |
| BoundMotorParamId | Guid | - | Y | 绑定的电机参数ID（仅当BindingType=1时） |
| BoundProjectorParamId | Guid | - | Y | 绑定的投射器参数ID（仅当BindingType=2时） |
| BoundGimbalGroupId | Guid | - | Y | 绑定的云台组ID（三目设备电机绑定时，关联AbpProCalibGimbalGroups） |
| BindingStatus | int | - | N | 绑定状态（0=待绑定，1=已绑定，2=校验中，3=验证失败） |
| StatusMessage | nvarchar | 512 | Y | 状态信息（失败原因等） |
| CreationTime | datetime2 | - | N | 创建时间 |
| CreatorId | Guid | - | Y | 创建人ID |
| LastModificationTime | datetime2 | - | Y | 最后修改时间 |
| LastModifierId | Guid | - | Y | 最后修改人ID |
