# 相机页操作逻辑

## 1. 基础预览控制

按钮：开始预览 / 停止预览
点击「开始预览」：相机开始采集，左侧画布显示实时图像，右上角实时刷新当前 FPS。
点击「停止预览」：相机停止采集，预览画面冻结 / 清空，FPS 显示消失。

## 2. 曝光 / 测光核心参数

目标灰度值 数值输入框（0.1-90）
测光区域占比 百分比输入框（0.1-50）

## 3. 曝光模式逻辑（三选一）

### 模式 1：Off（手动曝光）

显示字段：

曝光时间输入框（单位：us）

操作逻辑：

用户直接输入曝光时间，相机按设定值固定曝光，不自动调整。

### 模式 2：Once（单次自动曝光）

显示字段：

「执行单次自动曝光」按钮

曝光状态（Idle/Adjusting/Completed）

曝光时间输入框（可手动修改）

曝光检测区域设置：宽度、高度、起始 X、起始 Y

自动曝光时间范围：最小值、最大值

操作逻辑：

用户设置好目标灰度、测光区域、时间范围。

点击「执行单次自动曝光」，相机在曝光范围内调整到目标灰度。

调整完成后曝光状态显示 Completed，曝光时间锁定，用户可手动微调。

模式 3：Continuous（连续自动曝光）

### 显示字段

曝光状态（Idle/Adjusting）

曝光时间输入框（可手动修改，自动调整时会被覆盖）

曝光检测区域设置：宽度、高度、起始 X、起始 Y

自动曝光时间范围：最小值、最大值

操作逻辑：

相机持续根据当前画面亮度，在时间范围内动态调整曝光时间，维持目标灰度。

用户可手动设置检测区域和时间范围，限制自动调整的边界。

## 4. 增益模式设置（下拉选择）

选项：HighCapacity（高容量） / Balanced（平衡） / Sensitive（高灵敏度）

操作逻辑：用户选择后立即生效，相机增益模式切换，影响帧率 / 噪声 / 动态范围表现。

# 投影仪页操作逻辑

## 1. 基础参数设置

- 投影控制区
  - 按钮：开灯 / 关灯
  - 亮度输入：0-175（默认建议 75）
  - 光源选择：白光 / 红光 / 绿光 / 蓝光
  - 操作逻辑：
    - 点击「开灯」后开启投影 LED；点击「关灯」后关闭 LED。
    - 修改亮度后立即生效；当亮度大于 100 时，界面提示“注意散热”。
    - 颜色切换后立即生效；若后续需要调 RGB 通道亮度，需要提示用户先切换到白光模式。

- 投影模式区
  - 内置图案：黑图 / 白图 / 十字图 / 棋盘格
  - 棋盘格尺寸：整数输入框
  - 触发模式：普通触发 / 循环触发 / 单帧触发
  - 操作逻辑：
    - 选择内置图案后可立即下发设备显示。
    - 选择棋盘格时，允许额外设置棋盘格像素尺寸。
    - 触发模式仅影响“下载后的条纹序列播放”，不影响内置静态图案显示。

## 2. 图案生成

- 图案类型
  - 棋盘格
  - 横纹
  - 竖纹
  - 左斜纹
  - 右斜纹

- 图案参数
  - 仅允许用户设置：宽度(max 1280)、高度(max 720)
  - 固定周期集合：5、10、20、40、80、160、320、640
  - 每周期固定生成 2 张图
  - 固定相位：
    - 第 1 张：0π
    - 第 2 张：1π
  - 灰度固定：
    - 最小灰度 = 0
    - 最大灰度 = 255

- 生成逻辑
  - 点击「生成图案」后，前端按当前宽高分别生成 5 类图案。
  - 每类图案按固定周期集合分组生成，每组包含 2 张相位图。
  - 图案以 SVG data URL 形式在前端生成，直接供 Vue 页面预览，不依赖后端即时出图。
  - 生成结果仅更新当前页面内存数据；用户点击下载前，不写入设备。

- 条纹方向说明
  - 横纹：沿 Y 方向交替变化
  - 竖纹：沿 X 方向交替变化
  - 左斜纹：按 -45° 方向变化
  - 右斜纹：按 45° 方向变化
  - 棋盘格：X / Y 两方向同时变化

## 3. 预览图案

- 预览布局
  - 一级分组：图案类型
  - 二级分组：周期
  - 组内内容：当前周期对应的 2 张相位图

- 显示内容
  - 缩略图
  - 图案类型
  - 周期值
  - 帧序号（Frame 0 / Frame 1）
  - 相位值（0π / 1π）
  - 当前图像分辨率

- 交互逻辑
  - 点击缩略图后，在右侧 / 弹窗大图区域显示当前图案。
  - 切换宽高并重新生成后，预览区整体刷新。
  - 未生成图案时，预览区显示空状态提示。
  - 预览仅用于页面展示，不代表已经下载到投影仪。

## 4. 下载图案

- 下载选择
  - 支持按“图案类型 + 周期 + 帧序号”勾选下载项
  - 支持全选 / 全不选 / 按周期批量选择
  - 支持拖拽或上下移动调整最终下载顺序

- 下载约束
  - 投影仪最多支持 100 幅用户条纹；超限时禁止提交并提示用户

- 下载过程中显示：当前张数 / 总张数、进度条、当前状态、失败原因
- 下载完成后提示成功，并允许用户立即执行一次投影测试

- 下载后控制
  - 按钮：投影一次 / 循环投影 / 单步下一张 / 停止投影
  - 操作逻辑：
    - 「投影一次」：按当前保存的序列完整播放一轮
    - 「循环投影」：循环播放当前序列，直到用户主动停止
    - 「单步下一张」：仅在单帧触发模式下可用
    - 「停止投影」：停止当前序列输出，恢复空闲状态
