# 内参照片质量评分接口变更说明

更新日期：2026-08-20  
适用范围：标定 Step 5 前端、`CalibPhotoDto`  
基础路由：`/api/app/calib-photo`

## 1. 变更摘要

内参拍照完成后，后端会对照片计算两个独立的 1–100 分质量指标，并随照片 DTO 返回：

- `exposureScore`：曝光质量评分。
- `sharpnessScore`：清晰度评分。

本次为向后兼容的 DTO 字段扩展，不修改现有请求参数、路由、照片有效性判断或标定计算逻辑。

评分当前仅对新拍摄的内参照片生效。外参照片、双目成对照片以及本功能上线前保存的历史照片均返回 `null`。

## 2. 受影响接口

### 2.1 内参拍照

```http
POST /api/app/calib-photo/take-intrinsic-photo
Content-Type: application/json
Authorization: Bearer <token>
```

请求体不变：

```json
{
  "calibProjectId": "<标定项目ID>",
  "cameraDeviceId": "<相机设备ID>"
}
```

返回的 `CalibPhotoDto` 新增评分字段。

### 2.2 照片列表

```http
GET /api/app/calib-photo/photo-list?calibProjectId=<项目ID>&cameraDeviceId=<相机ID>&photoType=0
Authorization: Bearer <token>
```

列表中的每个 `CalibPhotoDto` 均包含新增字段。`photoType=0` 表示内参照片。

## 3. DTO 变化

`CalibPhotoDto` 新增：

| 字段 | TypeScript 类型 | 范围 | 说明 |
| --- | --- | --- | --- |
| `exposureScore` | `number \| null` | 1–100 | 曝光质量，分数越高表示曝光越合适 |
| `sharpnessScore` | `number \| null` | 1–100 | 图像清晰度，分数越高表示边缘越清晰 |

推荐的前端类型定义：

```ts
export interface CalibPhotoDto {
    id: string
    photoType: CalibPhotoType
    isValid: boolean
    cornerCountDetected: number
    exposureScore: number | null
    sharpnessScore: number | null
    capturedAt: string
    thumbnailBase64: string | null
    pairGroupId: string | null
    stereoRole: StereoPhotoRole | null
    extrinsicPhase: ExtrinsicPhotoPhase | null
    imageDiffScore: number | null
    imageDiffSignificant: boolean | null
}
```


前端必须把 `null` 视为“无评分数据”，不能显示为 `0` 分。

## 5. 评分规则与业务含义

- 分数为整数，范围固定为 1–100。
- 优先使用检测到的标定板区域评分，区域为特征点外包围框并向外扩展 10%。
- 标定板检测失败时，评分区域回退为整张图片。
- 曝光评分综合灰度均值、过曝像素比例和欠曝像素比例。
- 清晰度评分基于灰度图边缘响应。
- 评分仅作为拍摄质量提示，不参与 `isValid` 判断，也不会阻止照片保存或标定计算。

因此，`isValid` 与两个评分需要独立展示：照片可能角点检测有效但质量评分较低，也可能角点检测失败但仍有整图评分。

## 6. 前端展示建议

仅在对应值不是 `null` 时显示评分：

```vue
<span v-if="photo.exposureScore !== null">
    曝光质量 {{ photo.exposureScore }}
</span>
<span v-if="photo.sharpnessScore !== null">
    对焦清晰度 {{ photo.sharpnessScore }}
</span>
```

现有前端已在内参照片缩略图底部显示两个评分，并复用以下国际化文本：

- `camera.apertureScore`：曝光质量。
- `camera.focusScore`：对焦清晰度。

前端不应根据分数自行修改 `photo.isValid`，也不应使用评分过滤标定输入照片。

## 7. 生效范围

| 照片类型 | `photoType` | 是否生成评分 |
| --- | ---: | --- |
| 内参照片 | `0` | 是，仅新拍摄照片 |
| 投影外参照片 | `1` | 否，返回 `null` |
| 双目成对照片 | `2` | 否，返回 `null` |

双目成对拍照暂不接入本评分功能。

## 8. 前端联调检查项

1. 内参拍照成功后，响应中的两个评分均为 1–100 的整数。
2. 新照片无需刷新页面即可在缩略图上显示评分。
3. 重新加载照片列表后，评分与拍照响应保持一致。
4. 历史照片评分为 `null` 时不显示评分标签。
5. 外参和双目成对照片不显示评分标签。
6. 评分高低不改变有效/无效标签及后续标定操作。
