## Step6 在线扫描完整流程细化

### 6.1 双目无光预览模式

1. 模式初始化：双相机同步开启。
2. 帧率调度：拉取程序兼容硬件最大同步帧率，左右相机严格同帧曝光、同步采图。
3. 深度运算：实时执行双目立体匹配算法，生成稠密深度图。
4. 图像渲染：深度值映射伪彩色梯度（近暖远冷 / 自定义色阶），叠加原始纹理得到带深度色彩融合图。
5. 前端推送：帧数据编码后实时流式下发前端展示，附带帧率、深度有效率、视差置信度状态。

### 6.2 单目一光（单相机 + 结构光投影仪）

1. 硬件上电：开启结构光投影光源，切换投影图案为标准棋盘格标定图案。
2. 第一轮采集：固定棋盘格尺寸，拍摄第一张彩色原图。
3. 第二轮采集：投影仪参数微调，缩放/微调棋盘格方格尺寸，拍摄第二张彩色原图。
4. 第三轮采集：再次变更棋盘格尺度，拍摄第三张彩色原图。
5. 多尺度棋盘格作用：覆盖远近不同景深区域，提升相位匹配、三维重建鲁棒性。
6. 重建计算：基于多帧结构光相位/棋盘特征解算像素三维坐标，生成深度图。
7. 输出渲染：深度映射彩色贴图，实时推送带深度色彩效果图至前端。

### 6.3 双目一光（双相机 + 单台结构光投影仪）

流程逻辑与单目一光采集步骤完全对齐，区别在于采图单元：

1. 开灯切棋盘格图案，双相机同步采集第一组左右彩图。
2. 调整棋盘格尺寸，同步采集第二组左右彩图。
3. 再次调整棋盘格尺寸，同步采集第三组左右彩图。
4. 融合重建：同时利用双目视差约束 + 结构光相位约束联合解算三维点云。
5. 渲染输出：点云深度上色生成融合彩图，实时流式推送到前端界面。

### 6.4 可实现性结论

可以实现，且可复用现有能力：

1. 相机预览与推流：复用相机实时预览服务与 SignalR 通道。
2. 投影仪控制：复用开灯/关灯、显示模式、棋盘格尺寸调节能力。
3. 标定参数：复用 Step5 的内外参结果、双目校正参数与 map 结果。

### 6.5 研发实现起步建议

1. 第一阶段：先打通在线扫描会话生命周期（启动、停止、状态查询、前端推流）。
2. 第二阶段：接入双目无光深度链路（立体校正 + 视差 + 伪彩渲染）。
3. 第三阶段：接入单目一光与双目一光多尺度采集编排与融合重建。
4. 第四阶段：补齐质量指标上报（fps、深度有效率、置信度、重建耗时）。
