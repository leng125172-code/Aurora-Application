## 维护约定

1. 文件名应描述业务主题，避免使用“新建文档”“最终版”等模糊名称。
2. Markdown 内部链接使用相对路径；移动文件时同步检查链接。
3. 厂商原始文件及其配套 `.files` 目录必须一起移动。
4. 临时日志放入 `08-日志与调试`，确认无长期价值后再清理。
5. 同一主题存在多个需求稿时，先保留历史文件，再在主文档中标明当前有效版本。
