# 前端 AI 实现任务：算子参数说明完整展示

## 目标

修改算子选择面板和算子详情/配置面板，完整展示三类参数：

1. 入参说明：`inputPorts`。
2. 配置参数说明：`configFields`。
3. 出参说明：`outputPorts`。

不得只显示参数名称。每项必须展示接口返回的 `description`。这里的 `description`
不是普通字段释义，而是直接面向操作人员的“如何配置/连接该参数”指南。

## 数据接口

```http
GET /api/app/workflow-node-palette
```

响应结构：

```ts
interface OperatorPortDefinition {
  name?: string
  displayName?: string
  description: string
  portTypeName: string
  defaultValue?: unknown
  valueLimit?: unknown
  errorCheck: boolean
  controlType: number
  matType: number
}

interface OperatorConfigFieldDefinition {
  name: string
  displayName?: string
  description: string
  valueTypeName: string
  defaultValue?: unknown
  valueLimit?: unknown
  required: boolean
  controlType: number
}

interface WorkflowNodeDefinition {
  id: string
  nodeType: string
  displayName: string
  description?: string
  inputPorts: OperatorPortDefinition[]
  configFields: OperatorConfigFieldDefinition[]
  outputPorts: OperatorPortDefinition[]
}
```

后端保证所有算子的三类参数 `description` 非空。前端不得自行拼接或覆盖说明。
说明采用短句，只保留连接/填写方式、类型、必填状态、默认值、范围/选项及输出用途。

## UI 要求

算子详情按以下固定顺序展示：

```text
算子名称
算子功能说明
├── 入参
├── 配置参数
└── 出参
```

每个参数至少展示：

- 显示名称：`displayName || name`。
- 程序参数名：`name`。
- 配置指南：`description`，原文完整展示，告诉用户该参数怎么填、怎么连或怎么使用。
- 数据类型：入出参使用 `portTypeName`，配置参数使用 `valueTypeName`。
- 默认值：存在时展示。
- 范围或选项：`valueLimit` 存在时展示。
- 配置参数是否必填：`required`。

某类参数数组为空时显示“无入参”“无配置参数”或“无出参”，不能隐藏整个说明区域。

## 推荐组件

```text
OperatorDocumentation
├── OperatorParameterSection kind="input"
├── OperatorParameterSection kind="config"
└── OperatorParameterSection kind="output"
```

参数说明较长时允许折叠，但默认至少展示两行；鼠标悬停或展开后必须能看到全文。

## 编辑器提示

代码编辑器的算子自动完成和悬浮提示同样使用后端说明。后端已按“入参、配置参数、出参”生成 Markdown 文档，前端直接渲染 `documentation` 或 `hover.markdown`，不要只保留签名。

## 禁止事项

- 不要只显示 `displayName`。
- 不要把配置参数混进入参列表。
- 不要把出参当成可编辑配置。
- 不要硬编码某个算子的说明。
- 不要根据字段名称在前端猜测说明或重新生成配置建议。
- 不要在 `description` 为空时导致页面报错；兼容旧缓存可回退显示“暂无说明”。

## 验收标准

- [ ] 所有算子均可打开详情。
- [ ] 每个入参均显示名称、类型和说明。
- [ ] 每个配置参数均显示名称、类型、说明、默认值/范围和必填状态。
- [ ] 每个出参均显示名称、类型和说明。
- [ ] 空参数分类显示明确的空状态。
- [ ] 自动完成详情包含三类参数说明。
- [ ] hover 提示包含三类参数说明。
- [ ] TypeScript 类型包含三个 `description` 字段。
- [ ] `vue-tsc --noEmit` 通过。
