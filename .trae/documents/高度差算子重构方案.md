# 高度差算子重构方案

## 需求分析

用户要求：
1. **删除 `aggregate_regions` 算子** — 将聚合逻辑合并到 `plane_height_diff` 算子中
2. **扩展 `plane_height_diff` 算子** — 输出包含基准区域和目标区域信息的 JSON 结构体，格式为：
   ```json
   {
     "refRegion": {"name": "A", "x": ..., "y": ..., "z": ...},
     "targetRegion": {"name": "B", "x": ..., "y": ..., "z": ...},
     "signedDiff": 2.22,
     "absDiff": 2.22,
     "isOk": true
   }
   ```
3. **输出变量类型** — `valueType: string`, `scalarValue: JSON`

## 修改内容

### 1. 修改 `plane_height_diff.cs`

**新增输入参数：**
- `ref_region_name` — 基准区域名称（配置参数）
- `target_region_name` — 目标区域名称（配置参数）
- `ref_cloud` — 基准区域点云（用于计算基准区域质心）

**修改输出 JSON 结构：**
```json
{
  "refRegion": {
    "name": "A",
    "x": -16.96,
    "y": 5.58,
    "z": -0.0044
  },
  "targetRegion": {
    "name": "B",
    "x": -18.90,
    "y": -2.34,
    "z": 2.2178
  },
  "signedDiff": 2.226382,
  "absDiff": 2.226382,
  "minDiff": -0.5,
  "maxDiff": 0.5,
  "isOk": true
}
```

### 2. 删除 `aggregate_regions.cs`

直接删除该文件。

### 3. 修改工作流脚本 `create_height_diff_workflow.py`

**移除节点：**
- `aggregate_regions` 节点

**调整连接：**
- `plane_height_diff` 节点新增连接 `ref_cloud` → 基准区域点云
- 结束节点直接使用 `result_json`（来自 `plane_height_diff`）
- 移除 `is_ok` 汇总节点（改为从 `plane_height_diff` 读取）
