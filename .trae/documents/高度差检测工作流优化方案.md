## 三、修改方案

### 3.1 修复 `AnnotateRegion` 类（需求一 + 需求三）

**文件**：`Sources/AuroraStruct3D/AuroraStruct3D.OpenCV/RoiOps/annotate_height_diff_result.cs`

在 `AnnotateRegion` 类中新增三个字段：

```csharp
public class AnnotateRegion
{
    public string Name { get; set; } = string.Empty;
    public double Height { get; set; }
    public RoiMetadata Roi { get; set; } = new();
    public RoiProjectionMapping? ProjectionMapping { get; set; }
    // 新增字段
    public double[]? PlaneParams { get; set; }
    public List<RoiPoint>? OutlinePoints { get; set; }
    public bool IsSelected { get; set; }
}
```

同步修改 `DrawRoi` 方法：
- 当 `OutlinePoints` 不为空时，使用 `Cv2.Polylines` 绘制平面轮廓边框线（替代或补充 ROI 轮廓）
- 被选中平面（`IsSelected = true`）使用高亮颜色（如亮绿色），未选中使用对应颜色
- 保留 ROI 轮廓作为参考（可选，用虚线或半透明方式）

### 3.2 新建 `render_plane_outlines` 算子（需求三）

**文件**：`Sources/AuroraStruct3D/AuroraStruct3D.OpenCV/RoiOps/render_plane_outlines.cs`

**Guid**：新生成

**设计思路**：
- 从 `regions_json` 中读取每个区域的 `OutlinePoints`（由 `aggregate_regions` 的 `ComputePlaneOutline` 计算）
- 在输入图像上用 `Cv2.Polylines` 绘制平面轮廓边框线
- 区分选中/未选中：选中平面用亮绿色（`#00FF00`），线宽 3px；未选中用对应颜色，线宽 2px
- 在轮廓旁标注区域名称

**输入端口**：
- `input_mat`（Mat）— 输入图像
- `regions_json`（string）— 区域数据 JSON（含 `OutlinePoints`、`IsSelected`）

**输出端口**：
- `output_mat`（Mat）— 叠加了平面轮廓的输出图像

**配置参数**：
- `outlineThickness`（int，默认 2）— 未选中轮廓线宽度
- `highlightThickness`（int，默认 3）— 选中轮廓线宽度
- `highlightColor`（string，默认 "#00FF00"）— 高亮颜色（十六进制）

### 3.3 更新 `annotate_tilted_view_result` 算子（需求二 + 需求三）

**文件**：`Sources/AuroraStruct3D/AuroraStruct3D.OpenCV/RoiOps/annotate_tilted_view_result.cs`

**改动内容**：
- 新增输入端口 `regions_json`（string）— 区域数据 JSON
- 读取 `regions_json` 中的 `OutlinePoints`，在倾斜视图上绘制平面轮廓
- 读取 `result_json`（string）— 测量结果 JSON，在倾斜视图上绘制高度差数值
- 保留 OK/NG 状态文本

### 3.4 修改工作流脚本（需求一、二、三）

**文件**：`Tools/create_height_diff_workflow.py`

**当前拓扑问题**：
1. 所有区域共用一个全局 RANSAC 拟合平面（`ref_plane`），通过 `z_channel_stats` 计算平均高度
2. `height_diff_range_eval` 仅比较 height_a 和 height_b（A vs B）
3. 倾斜视图参数用 `tiltAngle`（单参数），应改为 `tiltAngleY` + `tiltAngleX`

**目标拓扑**：

```
读取点云 → 体素下采样 → 统计滤波 → Z轴着色 → 彩色点云存Blob
                              ↓                    ↓
                        彩色点云转图像(preview)
                              ↓
              ┌───────────────┼──┬──┬──────────────┐
              ↓               ↓  ↓  ↓              ↓
         ROI分区(A)    ROI分区(B/C/D同理)
              ↓               ↓
         掩膜裁剪          掩膜裁剪
              ↓               ↓
     RANSAC拟合(A平面)  RANSAC拟合(B/C/D各自平面)
     [ref_plane]          [plane_B, plane_C, plane_D]
              ↓               ↓
         区域着色          区域着色
              ↓               ↓
              └───────┬───────┘
                      ↓
         ┌────────────┼────────────┐
         ↓            ↓            ↓
   plane_diff(B-A) plane_diff(C-A) plane_diff(D-A)
         ↓            ↓            ↓
         └────────────┼────────────┘
                      ↓
              聚合区域数据(含平面参数、轮廓点、高度差)
                      ↓
              ┌───────┴───────┐
              ↓               ↓
    平面轮廓渲染(俯视图)  倾斜视图(双轴30°+30°)
              ↓               ↓
         结果图标注        倾斜平面轮廓渲染
              ↓               ↓
         存Blob            倾斜视图标注
              ↓               ↓
         存Blob(tilted)    存Blob(tilted)
              ↓               ↓
              └───────┬───────┘
                      ↓
                   结束节点
```

**具体改动**：

1. **新增算子 GUID**（脚本常量区）：
   - `OP_RENDER_PLANE_OUTLINES` — 新算子 GUID

2. **为每个区域添加独立 RANSAC 拟合**（替换 `z_channel_stats` 或与其并行）：
   - 区域 A 的 RANSAC 拟合输出 `plane_params` → 绑定到 `ref_plane`（基准面）
   - 区域 B/C/D 的 RANSAC 拟合输出 → 绑定到 `plane_B_params`、`plane_C_params`、`plane_D_params`
   - 同时保留 `z_channel_stats` 输出 `region_{i}_inlier_cloud`（供 `aggregate_regions` 计算轮廓用）

3. **新增 `plane_height_diff` 节点**（B-A、C-A、D-A）：
   - 输入 `ref_plane_params` → `ref_plane`
   - 输入 `target_plane_params` → `plane_B_params` / `plane_C_params` / `plane_D_params`
   - 输入 `target_cloud` → `region_2_cloud` / `region_3_cloud` / `region_4_cloud`
   - 输出 `is_ok` → `is_ok_2` / `is_ok_3` / `is_ok_4`

4. **新增 `render_plane_outlines` 节点**（俯视图 + 倾斜视图）：
   - 俯视图：输入 `input_mat` → `preview_image`，`regions_json` → `regions_json`
   - 倾斜视图：输入 `input_mat` → `tilted_preview_image`，`regions_json` → `regions_json`

5. **更新倾斜视图节点参数**：
   - 将 `tiltAngle: 30` 改为 `tiltAngleY: 30, tiltAngleX: 30`

6. **更新结束节点输出变量**：
   - 移除 `signedDiff`（单一值），改为多组结果
   - 新增 `isOk` 汇总（B-A、C-A、D-A 全部 OK 才算 OK）
   - 保留 `resultJson`、`resultImageUrl`、`tiltedImageUrl`

7. **移除 `height_diff_range_eval` 节点**（被 `plane_height_diff` 替代）

### 3.5 ROI 选区交互逻辑（需求四）

**设计说明**：

在当前架构中，每个 ROI 通过 `掩膜裁剪 → RANSAC 拟合` 链路，已隐式实现了"ROI 选中对应平面"的效果——每个 ROI 裁剪出的点云所拟合的平面，就是该 ROI 对应的平面。

对于需求四中的"匹配规则"（在 ROI 范围内占比最大、平面中心最靠近 ROI 中心），在单 ROI 对应单平面的场景下天然满足。

**具体实现**：
- `aggregate_regions` 中已记录每个区域的 `IsSelected` 标志（目前基准区域 A 为选中）
- `render_plane_outlines` 中根据 `IsSelected` 使用不同颜色/线宽区分选中/未选中平面
- 若未来需要从多个候选平面中匹配，可创建 `match_plane_to_roi` 算子，当前暂不实现
